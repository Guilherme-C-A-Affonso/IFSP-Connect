Projeto: IFSP Connect

Autor: Guilherme Affonso

Curso: Engenharia de Computação

Objetivo

Criar um website utilizando HTML (estrutura), CSS (estilização) e JavaScript (interatividade) para aplicar os conceitos apresentados em aula.

Apresentação

No IFSP Connect, você encontrará recursos referentes à unidade do câmpus Guarulhos do Instituto Federal de São Paulo. Aqui, os alunos, professores e demais usuários poderão encontrar todas as informações desejadas sobre a instituição.

O IFSP Connect é um website fictício criado para acompanhar as aulas do curso de Desenvolvimento Front-End. A cada missão, novas funcionalidades serão adicionadas ao projeto, permitindo a aplicação, na prática, de conceitos estudados.

Ao final das três unidades, o IFSP Connect terá evoluído para uma aplicação web completa.

O projeto finalizado conterá diversas páginas, catálogo de recursos, área de notícias, interface responsiva, agenda de eventos, galeria de imagens, entre outros.
